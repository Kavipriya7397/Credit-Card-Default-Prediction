
# Credit Card Default Prediction

## Project Overview
This project analyzes credit card customer data and predicts
whether a customer may default on their payment using an
MLP (Multi-Layer Perceptron) classifier.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
1. Dataset loading and data-quality checks
2. Exploratory Data Analysis (EDA)
3. Data preprocessing
4. MLP model training
5. Model evaluation
6. Visualization of results

## Evaluation Metrics
Accuracy, precision, recall, F1-score, ROC-AUC,
and average precision.

## Outputs
The outputs folder contains generated visualizations,
evaluation metrics, test predictions and the trained model.

## How to Run
Open the notebook in Google Colab, upload the required CSV
dataset, and execute the cells in order.

## Note
Model results depend on the dataset and experimental setup.
